# UTS_ML-2
Segmentasi Pelanggan berdasarkan Probabilitas Churn dan Estimasi Waktu Pelanggan Bertahan

Project mengintegrasikan tiga metode machine learning, yaitu XGBoost untuk prediksi churn, Random Survival Forest (RSF) untuk analisis survival time yang kemudian menjadi fitur untuk dan segmentasi pelanggan menggunakan K-Means.
